04 — Colour Usage
When to use each colour
Navy #051B38Primary background (dark posts)
Orange #FBA919Accents, CTAs, highlights
Light Navy #0A2E5CHover tones, split panels
Surface #F8FAFCLight post backgrounds
✓ Dark post
Navy background + white headline + orange accent word. Grid overlay at 4% opacity. Logo always white/orange.
✓ Light post
White or #F8FAFC background + navy headline + orange accent. Subtle slate borders. Logo in navy/orange.
✓ Orange post
Orange background only for CTAs or major announcements. Logo goes navy on orange. One per content cycle.
✕ Never mix
Never place the orange logo on an orange background. Never use random off-brand colours or gradients. Never invert the V-mark colour system.

06 — Copywriting Rules
Text on every post
✓ Headline rule
2–6 words. Start with a verb or bold noun. One orange accent word. Never sentence-case headlines — use title structure: "Build better systems."
✓ Support copy
Max 2 lines. 18–22 words. Muted (50% opacity on dark, slate on light). Always reinforces the headline — never introduces new ideas.
✓ Category pills
Always label the post type: Web Dev · Mobile App · SaaS Tool · Product · Announcement · CTA · EdTech · Case Study.
✕ Avoid
Avoid word counts over 25 in body copy. Avoid exclamation marks. Never use casual lowercase "vylex" without the logo V-mark. Never omit the domain.
